How to read the board

  • ♛︎ A queen being tried
  • ♛︎ Safe, so the queen is placed
  • ✕ Rejected; the red line runs to the queen that attacks it
  • ↩ Backtrack: this queen is removed
  • ♛︎ A gold border marks a solution
  • ♛︎ A blue border marks the end of the search
